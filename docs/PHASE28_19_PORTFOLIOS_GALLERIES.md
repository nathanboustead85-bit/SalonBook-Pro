# Boustio Phase 28.19 — Staff portfolios and salon galleries

Isolated responsive portfolio concept at `web/phase28/portfolio-preview.html`, independent from the Phase 28.18 owner photo manager and existing booking pages.

The fictional Kody Blends gallery supports service, staff and salon filters, staff portfolio selection, accessible illustration labels, and empty states. Content is inline demo data rendered with DOM textContent, not user-supplied images. All entries must be explicitly approved, public, demo-only and scoped to the requested owner. This is a **policy model**, not Firebase authorization.

No booking, upload, messaging, payment, production publishing, storage or network operations occur. Existing appointments and production configuration remain untouched.

Launch blockers include verified business-owned image retrieval, photo consent and rights, moderation, secure image transformation, real Firebase emulator authorization and abuse tests, performance/accessibility review, Samsung device testing and explicit deployment approval.
