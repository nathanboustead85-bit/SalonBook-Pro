# Marketing analytics preview
Owner-only aggregate rows for promotions, loyalty, birthday, re-engagement and referrals. Issuance cohort uses [from,until), redemption before until, no customer or booking IDs returned. Redemption rate is redeemed events / issued events; customer uptake is unique redeemers / unique recipients, not population retention. Re-engagement uptake is a proxy, not verified incremental recovery. ROI preview = (supplied attributed pre-discount contribution margin minus discounts and campaign costs) / (discounts + campaign costs). Zero denominator unavailable. Reject duplicate event and booking attribution across kinds, malformed values and overflow. No live data or actual financial attribution. Production requires authoritative issuance/redemption/completion/payment/refund and cost records, trusted time, complete cohort data, attribution policy for stacked offers, incremental baseline, privacy thresholds, dashboard integration and independent verification. No deployment.
