# Promotions preview
Owner-only pure discount proposal. Uppercase ASCII codes, percentage 1–100 rounded down, fixed discount capped at price, seasonal validity [start, expiry), appointment must occur before expiry, optional first recorded completed visit restriction, optional UK local same-day hourly window, maximum 1–10000 uses and one use per customer and booking per code. Candidate/current snapshots must match. Returns revised ledger without persistence. No actual campaign or booking change. Production needs authoritative history, customer identity, server time, price and appointment data, stable offer identity, atomic booking/ledger transaction, concurrent quota enforcement, cancellation/refund rules, stacking policy, configurable timezone, secure customer-facing code entry and abuse prevention. No live deployment.
