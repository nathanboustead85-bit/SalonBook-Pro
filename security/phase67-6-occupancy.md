# Occupancy preview
Owner-only offline calculations. Caller supplies net bookable staff windows after breaks, holidays and time off; no schedule expansion or authoritative validation yet. Union overlapping windows and noncanceled appointments per staff; reject booked time outside capacity. Clip intervals to reporting range; cancellations use appointment start cohort and all statuses denominator. Canceled value is nominal appointment value, not proven lost revenue. Hour buckets use local clock hour, combining repeated DST hours; busiest weekday/date reporting not implemented. Booked occupancy includes future and overdue bookings, not actual attendance. Stable staff IDs, complete authoritative records, efficient interval indexing, real schedule integration, UI, backend and payment reconciliation pending. No live deployment.
