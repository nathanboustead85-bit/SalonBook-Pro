# Phase 61.18 privacy and safety
The **Share client contact** action is manual. Android's chooser displays before the user selects an app; Boustio does not send messages or share in the background. Only the client's name, phone and email are included. Private notes and booking history are excluded. The user is responsible for selecting a trusted destination and appropriate recipient. No new permissions, Firebase writes or network calls are introduced.

Preserve the existing isolated TEST package, stable signing key, saved client data and separate DEV installation with two original appointments. All seven launch blockers remain open. Live bookings, messaging, payments, reminders and deployment remain disabled.
