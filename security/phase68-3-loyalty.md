# Loyalty programme preview
Owner-only deterministic offline balances, visit units or integer points per pound of nominal completed appointment value, rounded down per booking. Only appointments starting on or after programme start count. Duplicate booking IDs reject the calculation; repeated calculations do not persist credits. No redemption, expiry, refunds, immutable credit ledger or customer-facing access yet. Programme changes currently recalculate historical credits; production must freeze earning rules per event, use authoritative completed/payment records and stable IDs, atomic idempotent ledger transactions, reversals, concurrency, tenant security and audit. Loyalty participation does not imply marketing consent. No live deployment.
