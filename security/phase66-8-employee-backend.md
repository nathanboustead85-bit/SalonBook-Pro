## Offline authorization contract
No endpoint or Firebase rule is activated. Trusted adapters must verify tokens, revocation and session freshness, fetch membership/policy/resource from authoritative tenant-scoped storage, and use a consistent transaction for authorization and mutations. Direct Firestore client access must be denied or equivalently enforced by tested rules. Never trust request role, grants, staff assignment or identity. Field-level response filtering is mandatory for contact data. Creation, reassignment, owner endpoints, audit atomicity, real emulator direct API tests and cross-device revocation remain open. No production deployment.
