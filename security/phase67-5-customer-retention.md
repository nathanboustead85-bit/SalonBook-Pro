# Customer retention preview
Owner-only offline analytics. New means first recorded completed visit in selected half-open range; returning means a completed visit before range and in range. Retention denominator is all prior observed completed customers, not a fixed acquisition cohort. Average visits per active customer in range. Lifetime value and inactivity use all supplied completed history through now, independent of selected period; incomplete history biases results. Inactivity uses caller-supplied cutoff, strictly before cutoff, and excludes customers without completed visits. No automatic outreach. No actual receipts or predictive lifetime value. Stable customer identity, complete authoritative history, pagination, server clock, permission enforcement, privacy retention policies and UI remain required. No live deployment.
