# Revenue foundations
Offline owner-only GBP appointment value projection, not payment receipts, accounting revenue or profit. Half-open appointment start time interval [from, until). Booked appointments before now are overdue, not automatically completed or no-shows. Completed, upcoming, canceled and overdue values are separate. No taxes, discounts, refunds, tips or payment reconciliation yet. Caller identity, clock and records are synthetic; authoritative server queries, complete pagination, timezone/calendar boundaries, payment ledger reconciliation and access controls are mandatory before production. No live services or UI changes.
