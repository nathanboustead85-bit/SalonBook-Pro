# Re-engagement preview
Owner-only consent-gated proposal using completed appointment history. Configurable 30–365 elapsed days inactivity and cooldown; upcoming booked appointments exclude customers. Configurable 1–100 percent comeback offer. One proposal per customer/campaign and cooldown across campaigns and channels when using the same complete ledger. Returns customer ID and discount, no contact details. No messages, storage, scheduling or actual offer issuance. Caller snapshots are not authoritative; production requires complete history, trusted clock, atomic durable campaign/outbox ledger, cross-channel suppression, verified consent/unsubscribe at send time, global frequency limits across other marketing types, secure offer binding and retention/privacy review. No deployment.
