# Referral preview
Owner-only pure qualification. Supplied uppercase alphanumeric codes 12–32 characters must be unique within tenant. Existing referrer must have completed a visit before code issuance; newcomer first recorded completed visit must start after issuance and code must still be valid at qualification. Fixed reward proposals 0–1000 GBP each, at least one positive. Duplicate newcomer and booking claims rejected, matching ledger and programme snapshots required. No contact details, sending, or actual credit issuance. Production requires cryptographically random code generation, verified identity and anti-Sybil checks, authoritative history and referral attribution at booking, actual completion time, trusted clock, atomic durable claim and reward ledger, refund reversal, rate limits, privacy and customer UI. Same-snapshot concurrent proposals are not atomic. No deployment.
