# Phase 59.12 — Integrated text, photo and voice messaging emulator tests

`chat/integrated-emulator-chat.cjs` composes the Phase 59.7 Firestore transactional message store and Phase 59.11 Firebase Storage emulator adapter. A real Firebase emulator suite verifies text message persistence, image upload with sanitization and linked Firestore message record, actual WebM voice duration processing and linked message, outsider denial, and disabled-by-default behavior. Both Firestore and Storage test rules deny all client access; server-side Firebase Admin is used against emulators only.

**Critical unfinished work:** The media upload currently happens before Firestore message creation. Rejected transactions, retries and duplicate requests can leave orphaned media objects. This is NOT production-safe until a reservation-first/idempotent upload workflow, cleanup/retention and quota controls are implemented. Trusted identities are synthetic; business routing and membership require server-verified auth in production. No malware scanning, hardened media sandbox, notifications, user-facing chat UI, real deployment or independent staging approval. G1–G7 remain OPEN. Live messaging, bookings, payments and deployment remain disabled. Original Android appointments were not accessed.
