# Phase 59.10 — Isolated media storage integration (NOT Firebase Storage)

Implemented `chat/staging-media-store.cjs` for **disposable local filesystem storage** of validated, re-encoded images and validated voice bytes, with authenticated participant checks on uploads and reads, server-generated paths, exclusive file creation, and no public URLs. It is disabled by default and restricted to a disposable test directory. The integration test uses actual Sharp image processing and checks read isolation and path traversal rejection.

**This is not yet Firebase Cloud Storage integration.** It is an executable storage seam for later emulator integration. Before live use: resolve membership server-side rather than accepting a supplied conversation object; implement a real Firebase Storage emulator adapter, authenticated upload/download authorization, durable retention/deletion, quotas, virus scanning, media sandboxing and abuse controls. Symlink-safe filesystem isolation is not a substitute for production object storage. No endpoints, notifications, Firebase writes, Firestore rules changes, Android changes or deployment. G1–G7 remain OPEN; live messaging and payments disabled.
